# 🌤️ Clima en tiempo real

Aplicación web que muestra el clima actual y el pronóstico de los próximos 5 días de cualquier ciudad del mundo.

🔗 **Demo:** https://rafapolo22.github.io/clima-tiempo-real/

## ✨ Funciones

- Buscar el clima de cualquier ciudad.
- 📍 Usar tu ubicación actual.
- Pronóstico de las próximas 12 horas y de 5 días.
- Mensajes según el clima (por ejemplo, "Lleva paraguas").
- Fondo animado según la condición: sol, nubes, lluvia, nieve o tormenta.
- Modo claro y oscuro, recordado en el navegador.
- Ciudades favoritas guardadas en el navegador.
- Instalable como app en el celular.

## 🛠️ Tecnologías

- HTML, CSS y JavaScript puro.
- [API de Open-Meteo](https://open-meteo.com/) para los datos del clima (gratuita y sin llave).
- Service Worker y Web App Manifest para instalarla como app.

## 🚀 Cómo ejecutarla

No necesita instalación. Puedes:

1. Abrir el enlace de la demo, o
2. Descargar el repositorio y abrir `index.html` en tu navegador.

> Nota: la función de ubicación requiere HTTPS, así que funciona en la demo y no al abrir el archivo directamente.
